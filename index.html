04 / THREAT AWARENESS

Know the Risks. Stay Protected.

⚠️ Open Wi-Fi

Open networks may not provide strong protection. Avoid sharing sensitive information on unknown networks.

📡 Fake Hotspot

Unknown hotspots can be misleading. Check the network name before connecting.

🔑 Weak Password

Weak passwords are easier to guess. Use long and unique passwords for better security.

🔄 Outdated Security

Keeping devices and network equipment updated helps improve security.

05 / GLOSSARY

Wireless Security Glossary

Understand common wireless security terms.

WPA2

A Wi-Fi security standard that uses encryption to help protect wireless networks.

WPA3

A newer Wi-Fi security standard designed to provide stronger protection.

SSID

The name used to identify a Wi-Fi network.

Encryption

A method of protecting information by converting it into a protected form.
